# Praetor

A product Arc10 built to make becoming an Akash Network provider simple, now sold to Akash Network.

## The problem

Akash Network is a decentralized cloud: people with spare compute rent it out as providers and get paid in AKT when deployers choose them. Setting up a provider meant working through a command-line interface, a barrier that kept many operators off the network.

## What Arc10 built

Praetor replaced the command line with a streamlined web app. In about 20 minutes it built a production-grade Kubernetes cluster on the operator's machine, made it Akash ready and set up the provider service. After that, a provider usually only had to adjust DNS and port settings before bidding on leases and earning AKT.

Around the app, Praetor offered:

- **A provider dashboard** for active leases, earnings estimates and quick changes to the provider machine.
- **A profitability calculator** that estimated what a provider would earn at the current AKT price.
- **A real-time status dashboard** showing Akash providers and their available resources, for the public and for deployers choosing where to deploy.
- **Managed services** for data centres that wanted to join the network without running the servers themselves.

## Outcome

Arc10 sold Praetor to Akash Network. Praetor's site now says it has been acquired by Akash Network and that provider setup lives in the Akash Provider Console.
