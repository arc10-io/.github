## Our products

### [Arclyx](https://arclyx.ai): AI agents for small businesses

Describe a job in one sentence and Arclyx builds an agent that does it with your email, calendar, files and team tools. Try it first on a dry run, which reads your real tools and holds anything it would post or send, then let it run on a schedule, on a webhook or when someone @mentions it in Slack.
