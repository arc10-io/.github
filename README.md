# Arc10 work showcase

Selected work from [Arc10 Technologies Inc.](https://arc10.io), an AI engineering partner based in Toronto, Canada. The org page lives in [`profile/README.md`](profile/README.md); this repository also holds one case study per project under [`showcase/`](showcase/).

## Client engagements

- [Akash Network Provider Console](showcase/akash/): open-source provider tooling for a decentralized cloud, used by 50%+ of community providers. Ongoing since 2022.
- [UniWhales](showcase/uniwhales/): Kubernetes scaling, an Airflow ETL rebuild and test automation in parallel; +40% transaction capacity, no downtime. 6 months.
- [CPOS / STARR](showcase/cpos/): real-time, PCI-DSS-aligned sales tracking for Ontario Government compliance reporting, live in production. 1 to 1.5 years.
- [Rose & MacDonald](showcase/rose-macdonald/): Business Central, a storefront, EDI and Canada Post connected through Python middleware. 1+ years.

## Products we built

- [Arclyx](showcase/arclyx/): Arc10's AI agent platform for small businesses, in production at [arclyx.ai](https://arclyx.ai).
- [Praetor](showcase/praetor/): a web app that made becoming an Akash Network provider simple, sold to Akash Network.

## How it's organised

```
profile/README.md          the arc10-io org page
showcase/<project>/        one case study per project: the problem, what we did,
                           the outcome, the stack, the engagement and links
```

Client outcomes are quoted as published in the case studies on [arc10.io/work](https://arc10.io/work). To talk about any of this work, [book a call with a senior engineer](https://arc10.io/contact).
